## 相关研究

| 文献 | 核验状态与用途 |

| [Weiskopf 与 Weng 2013](https://doi.org/10.1136/amiajnl-2011-000681) | 已核对题名、期刊和 DOI；全文直链访问不稳定。仅用于完整性、正确性、时效等数据质量背景，不借其证明本项目数值边界 |
| [Know Your Limits](https://arxiv.org/abs/2407.18418) | arXiv v3 题名与计划书一致。早期页面可能显示 The Art of Refusal；引用时应说明所用版本，不能因此认定原引用虚构 |

| [Faithfulness vs Safety](https://arxiv.org/abs/2601.11886) | 已核验官方摘要及版本。研究反事实医疗问答，不是 EHR 写入；本项目将其作为相关动机 |
| [AgentNoiseBench](https://arxiv.org/abs/2602.11348) | 已核验官方摘要；其用户与工具噪声评估并不等价于本项目的共享病历评分问题 |

| [Rethinking MedAgentBench 作者页面](https://www.centific.com/publications/rethinking-medagentbench-a-framework-for-fair-medical-llm-agent-evaluation) | 已读取作者摘要；OpenReview PDF 遭浏览器验证，因此不依赖未读全文细节。它已经研究评分器与无动作分支问题，论文不能声称首次审计该基准 |

计划书的七条引用均找到对应论文或正式条目；没有将检索受限误写为文献不存在。新增 Rethinking MedAgentBench 是为了限定创新范围。

## 模型与服务依据

主模型使用官方 [7B](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct-AWQ)、[32B](https://huggingface.co/Qwen/Qwen2.5-32B-Instruct-AWQ)、[72B](https://huggingface.co/Qwen/Qwen2.5-72B-Instruct-AWQ) 仓库。已用 hf CLI 读取公开仓库元数据并记录 SHA，没有下载权重。72B 的模型许可证与较小模型不同，应按该模型原许可使用。

[vLLM 官方接口文档](https://docs.vllm.ai/en/stable/serving/online_serving/openai_compatible_server/) 支持本项目采用的 chat completions 客户端协议。接口适配已连接 llama.cpp CPU 模型服务；vLLM 的三模型主体部署尚未执行。

[FHIR R4 HTTP 规范](https://hl7.org/fhir/R4/http.html) 用于区分外部资源创建与本地资源存储。保持 benchmark 简化 payload 的 SQLite 沙盒不具备完整 R4 校验，不能用它的成功提交推断标准 FHIR 服务也会接受。

## 本项目自己的假设

数值边界、同一时间结果冲突的容差、HbA1c 缺失分支的主解释、模型系列调整、SQLite 执行层和统计终点属于本项目的研究选择。它们不是以上论文证明的临床标准。每项选择都在实验协议中声明，并保留相关敏感性分析。
