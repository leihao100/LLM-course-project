Clinical Chart Safety midterm report

Main file: midterm_report.tex
Supporting files: neurips_2024.sty, results_macros.tex
References are embedded in the main TeX file; no BibTeX run is required.

Compile with:
  tectonic midterm_report.tex
or:
  latexmk -pdf midterm_report.tex

On Overleaf, upload the source ZIP and select midterm_report.tex as the main file.
The official NeurIPS 2024 style is preserved without modifications. The standard
preprint option displays the two authors. The template's body font and margins
are unchanged. Provenance and checksum are recorded in template-provenance.json.
